EXPERIENCE & VOLUNTEER

ประสบการณ์และจิตอาสา

2025 ต.หนองไผ่ อ.ธวัชบุรี

เคยฝึกปฏิบัติงาน ณ โรงพยาบาลส่งเสริมสุขภาพตำบลหนองไผ่ (รพ.สต.)

การฝึกปฏิบัติงานด้านสาธารณสุขปฐมภูมิ

  • เรียนรู้บทบาทและกระบวนการทำงานของการเป็นหมออนามัยในการดูแลชุมชน
  • พัฒนาทักษะและความสำคัญของการให้บริการ ซักประวัติ และต้อนรับผู้ป่วยในระดับท้องถิ่น
  • เรียนรู้ระบบคัดกรองเบื้องต้นและการประสานงานสุขภาพชุมชน
หมออนามัย การบริการผู้ป่วย ชุมชน
2024 Studio Shodwe

โครงการ YOUTH LEADERS NEXTGEN

โครงการผู้นำเยาวชนรุ่นใหม่และจิตอาสาเพื่อสังคม

  • เรียนรู้วิธีการดูแลและอำนวยความสะดวกให้ผู้พิการทางสายตา ณ มูลนิธิธรรมิกชนเพื่อคนตาบอดในประเทศไทย
  • เข้าร่วมโครงการปลูกต้นไม้เฉลิมพระเกียรติ เพื่อเพิ่มพื้นที่สีเขียวแก่ชุมชน
  • พัฒนาภาวะผู้นำและการทำงานเป็นทีมร่วมกับเพื่อนเยาวชนจากหลากหลายสถาบัน
จิตอาสา ดูแลผู้พิการทางสายตา ปลูกต้นไม้

GITHUB PAGES

วิธีอัปโหลดเว็บไซต์ขึ้น GitHub Pages

ขั้นตอนการเปิดใช้งานเว็บไซต์นี้นำไปใช้ออนไลนได้อย่างฟรีและง่ายดาย

1

บันทึกไฟล์เป็น index.html

เซฟไฟล์โค้ดทั้งหมดนี้ไว้ในชื่อไฟล์ index.html ไว้ในคอมพิวเตอร์ของคุณ

2

สร้าง Repository บน GitHub

เข้าไปที่ GitHub.com สร้าง Repository ใหม่ แล้วตั้งชื่อ (เช่น portfolio) ตั้งเป็น Public และอัปโหลดไฟล์ index.html ขึ้นไป

3

เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings > Pages เลือก Branch เป็น main แล้วกด Save รอเพียง 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ออนไลน์ทันที!
